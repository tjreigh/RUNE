Language notes

How RUNE works

version 0.7

01

Truth has a threshold

@chaos n makes a value true only when it is at least n. At chaos 500, even 1 is false. 

@chaos 500
if (499)
  1
else
  0
end if
02

Text is arithmetic

Strings collapse to the sum of their Unicode code points. That makes emoji and ordinary text valid numeric operands. 

rocket = "🚀"
face = "😀"
rocket - face  → 128
03

State sticks around

Variables and the chaos threshold persist in this expiring browser session. Failed runs never commit partial changes. 

answer = 40
answer = answer + 2
answer  → 42
